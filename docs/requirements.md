# AI Design — 需求设计文档

> 状态：**已确认并实施** · 日期：2026-11-11 · 目标仓库：https://github.com/Ltqq/ai_design
>
> 本文定义**一次性完整交付**范围，不拆 MVP/一期/二期。技术实现见 [technical-design.md](technical-design.md)。

## 1. 项目定位

AI Design 是一个内部使用的轻量化营销海报工具。运营人员不需要学习传统设计软件，通过 AI 创作设计图，或上传现成海报参考图，即可得到**可重复填充 Excel 数据的 HTML/CSS 模板**，以后更换内容就能快速导出新海报。

### 核心目标

1. **AI 生图做模板**：输入提示词，调用可配置的生图模型生成设计图，再由多模态 Agent 转成模板。
2. **上传图做模板**：上传参考图（PNG/JPG/WebP），直接让多模态 Agent 识别、重建可填充模板。
3. **Excel 填充内容**：导入 `.xlsx` 文件，选择要展示的数据，通过字段映射替换模板变量，预览、生成、导出海报。
4. **模板长期复用**：在模板库查看、使用、复制、修改、删除；已保存模板换数据无需重新调用 AI。

**核心原则：AI 负责视觉设计与模板结构；Excel 负责业务数据；程序负责确定性填充与最终渲染。** 模型名称、价格、折扣等最终展示数据必须取自用户明确选择的字段，不能让生图模型“画出”并固化数字。

## 2. 角色与页面

默认是单实例、内部使用的 Web 应用，不开发多租户、角色权限和团队协作功能。

| 页面 | 用户可完成的操作 |
| --- | --- |
| AI 创作 | 文字描述生图；上传参考图；选择尺寸；触发 AI 转模板；预览对比；用自然语言提修改意见；确认保存 |
| 模板库 | 查看缩略图、名称、尺寸；打开使用；复制、重命名、删除；对模板发起 AI 修改 |
| 数据填充 / 生成 | 上传 Excel；查看表格数据；选择要展示的行；把 Excel 列绑定到模板字段；预览实际填充效果；导出 PNG |
| 模型设置 | 分别配置多模态理解模型与图片生成模型的 API Base URL、API Key、Model ID；测试连通性 |

界面默认中文，重点提供大图预览和简单操作。**不建设 Canva 式拖拽画布、图层系统、复杂属性编辑器。**

## 3. 业务流程

### 3.1 路径 A：AI 生图 → 模板

1. 进入「AI 创作」，输入海报主题、风格、宣传意图和尺寸（例如“暗黑科技立体风，适合宣传热门 AI 模型”）。
2. 点击「AI 生图」，调用用户配置的图片模型，展示生成的参考图。
3. 点击「生成可复用模板」，将参考图交给多模态 Agent。
4. Agent 识别视觉布局、标题、模型卡片、装饰图、二维码位置等，将**需要替换的文字/图片区域**重建为 HTML/CSS + 变量占位符，生成模板字段说明。
5. 系统渲染 HTML 预览图。Agent 可根据预览截图修正明显的布局问题；用户可继续用自然语言提出修改要求。
6. 用户满意后填写名称并保存到模板库。

### 3.2 路径 B：上传参考图 → 模板

1. 上传 PNG/JPG/WebP 参考图。
2. 直接进入上述第 3～6 步，不必先调用生图模型。

上传图只是**视觉参考**，不能简单地将整图设置为背景后把新文字叠上去，否则原来的文字和价格还会残留。转换器应重建布局，把固定装饰和可填充字段分开；对无法准确分离的图像效果，允许使用独立装饰素材或由生图模型生成**不含文字的背景**。

### 3.3 路径 C：Excel → 填充 → 导出

1. 打开已有模板，上传 Excel 文件（`.xlsx`）。
2. 页面显示工作表数据和字段名称，用户选择宣传所需的行与列。
3. 把 Excel 列对应到模板字段；普通文字字段一对一绑定，重复卡片区域使用选中数据行循环填充。
4. 页面实时显示实际渲染海报；必要时可更换行、排序或编辑本次海报的文案字段。
5. 点击「导出 PNG」，获得最终宣传海报。
6. 下次继续选这个模板，上传新 Excel、换数据并导出，不再走 AI 转换。

**Excel 的固定列格式当前未定。** 本文不预设采购价格、售价、折扣、缓存价格等字段名，也不擅自规定计算公式。先按“读取 Excel 实际表头并让用户映射模板变量”设计；等用户确定格式后，支持用已确定的列名自动映射，保留必要的人工调整。

**采购成本不等于宣传售价。** 未明确确认售价/折扣来源及公式前，不自动将成本填入宣传价格位置，不自动计算或宣称营销折扣。

## 4. 模板内容与复用

### 4.1 模板组成

一个模板包含：

- `template.html`：布局和数据占位符；
- `style.css`：字体、颜色、排版、立体和光效等样式；
- `manifest.json`：模板名称、目标尺寸、可填充字段、重复区域定义；
- `assets/`：装饰背景、图形、图标等静态素材；
- `thumbnail.png`：模板列表缩略图。

模板支持**单值字段**（标题、副标题、活动说明、Logo/二维码图）与**重复数据区**（例如每个模型一张卡片）。循环卡片个数根据用户选中的 Excel 数据决定；模板自身负责布局，预览若容不下则需要让用户调整选择数量或通过 AI 修改版式，不引入通用自动重排引擎。

### 4.2 AI 修改模板

用户通过自然语言修改设计，例如“把主标题移到上面”“卡片立体感更强”“留二维码区域”“调成 1080×1440”。

每次修改重新让 Agent 生成完整 HTML/CSS/manifest 并重新渲染预览，**不直接人工改写 AI 生成的模板文件**。确认后才保存或替换模板内容。

### 4.3 海报输出

- 默认输出：**PNG**，按模板定义宽高导出。
- 默认提供竖版宣传尺寸（例：1080×1440），允许用户自定义模板尺寸。
- 预览与导出使用同一 HTML/CSS 渲染逻辑，避免预览与下载结果不一致。
- 背景、文字、装饰和重复数据都要出现在最终 PNG 中。

## 5. 模型配置与 Agent 行为

| 能力 | 具体要求 |
| --- | --- |
| 多模态模型 | 自定义 Base URL、API Key、Model ID；能够理解图像和生成 HTML/CSS；支持 Agent 所需工具调用 |
| 生图模型 | 独立配置 Base URL、API Key、Model ID；用于文字生成设计图，以及必要时生成无字装饰背景 |
| Agent 框架 | **必须采用成熟开源框架，不能手写 Agent 推理/工具循环** |
| Agent 反馈 | 提供生成中的步骤信息、预览图与修改入口 |
| 自动修正 | 用真实浏览器渲染截图反馈给多模态模型，修正明显的布局偏差；避免无上限反复调用 |
| 模板复用 | 已保存模板填入 Excel 不能依赖 AI 重新生成 |

并非所有宣称“OpenAI 兼容”的上游都同时支持图片输入、工具调用、图像生成或编辑；设置页需要能分别测试所需能力。只保证**实际通过能力测试的配置**可用于对应流程，不为各家特殊私有协议做通用兼容层。

## 6. 功能验收标准

| 编号 | 验收场景 | 完成判定 |
| --- | --- | --- |
| A01 | 配置模型 | 两类模型均能独立保存配置、测试调用，并在创作流程中使用 |
| A02 | 文字生图 | 输入描述可生成并展示真实参考图，且可继续转成模板 |
| A03 | 上传图转模板 | 上传参考图可生成 HTML/CSS、字段清单和预览；填充区域不与原图文字重影 |
| A04 | AI 修改 | 用自然语言重新生成模板，修改后预览确实变化，并且未手工编辑生成文件 |
| A05 | 模板管理 | 保存后重新打开仍可复用；支持列表、复制、重命名、删除 |
| A06 | Excel 解析 | 上传 `.xlsx`，能看见实际数据和列名；可选择多行并映射字段 |
| A07 | 数据填充 | 同一模板分别填入两组不同数据，图片的模型名/数字均与用户选定输入一致 |
| A08 | PNG 输出 | 下载的 PNG 尺寸与模板配置一致，文字、图片和二维码位置能正确渲染 |
| A09 | 独立复用 | 使用已存模板 + 新 Excel 导出，不产生任何 AI 调用 |
| A10 | 全流程运行 | 本地按 README 安装并启动后，可以不写代码地完成 A01～A09 |

验收中用**真实 Excel 文件、真实 HTML 渲染器、真实文件落盘**测试业务，不在测试里复制一套业务计算逻辑。真实模型调用作为配置好 API Key 后的端到端验证；普通自动测试不伪造“模型调用已成功”。

## 7. 明确不做的内容

不做传统在线设计器的拖拽/图层编辑；不做多人权限/多租户；不做营销投放系统、定时发布、渠道监控；不做通用计费与利润计算引擎；不做模板市场与购买系统；不做 PDF/SVG/视频输出；不做为了极低概率竞态而引入消息队列、分布式锁、复杂任务调度或额外微服务。

若未来确需增加保护机制或兼容能力，**先说明：实际会怎么坏、发生概率的判断依据、预计新增代码量与维护成本，得到明确同意后再实施**。

## 8. 待用户确认的事项（不影响先确认主体需求）

1. **Excel 格式**：由用户后续提供正式列名、工作表格式及价格/折扣取值规则；当前只定义通用列绑定机制。
2. **部署方式**：本设计默认内部单机、单实例 Web 应用及本地持久化；如希望公网开放或多实例部署，需要单独确认权限与存储需求。
3. **图片模板的还原标准**：目标是视觉风格接近、文本可替换、生成效果精美，不承诺任意上传图片都像素级 100% 还原。

除以上待定项，不额外扩大需求。确认本文件后，按 [技术设计](technical-design.md) 的完整范围一次性开发、运行与测试。

## 补充确认：对话式一体化创作（2026-11-11）

- 原「AI 创作」与「模型对话」合并为 `/create`，不再保留独立聊天导航；`/chat` 跳转工作台。
- 多轮对话由 Mastra Agent 调用生图、参考图转模板、修改 HTML 和保存模板等工具，不要求用户反复切页面。
- 当前会话的参考图、草稿、已保存模板与聊天历史持久化，切换会话或刷新后恢复。
- 右侧固定展示参考图和实际 HTML 渲染，可直接进入海报生成页。
- Excel 仅两列「模型名称」「折扣」，按原始文字填充，不做价格计算。
